# Rэd Fitness & Wellness — демо-макет сайта

Тёмный лендинг фитнес-клуба (Казань, пр. Ильгама Шакирова, 2) в стиле bold gym-дизайна:
чёрный фон, красный акцент, крупные заголовки, наложенные фото, «призрачный» вертикальный текст.

**Только фронтенд, без бэкенда** — форма заявки и кнопка «Вход» демонстрационные.

## Стек

- HTML + CSS + vanilla JS, без сборки и зависимостей
- Шрифты: Oswald + Inter (Google Fonts)
- Анимации: IntersectionObserver, лёгкий параллакс героя

## Запуск

Просто открыть `index.html` в браузере или:

```
python -m http.server 8734
```

## Содержимое

- Реальные данные клуба: адрес, телефон, Telegram / WhatsApp / VK, рейтинг 5.0 на Яндекс Картах
- Отзывы и имена специалистов — из реальных отзывов на Яндекс Картах
- Фото: Unsplash (бесплатная лицензия) + фото клуба с официальной страницы

## Структура

```
index.html      — разметка всех секций
css/style.css   — стили, адаптив, анимации
js/main.js      — меню, шапка, параллакс, reveal, демо-форма
img/            — изображения
```
